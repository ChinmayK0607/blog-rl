# Experiment results

All reported rates are computed from committed raw rows. The frozen arena uses
60 seeds and four message conditions per seed (`generated`, `dropped`,
`reference`, and `shuffled`).

## Untouched Qwen3-4B arena baseline

`base/arena/` was generated by `Qwen/Qwen3-4B-Instruct-2507` through the
OpenAI-compatible Prime-RL inference server. In the generated-message condition:

- strict action rate: 0.9417;
- message strict rate: 0.5125;
- optimal outcome rate: 0.0167 (1/60);
- mean oracle regret: 3.23;
- mean environment reward: -0.585;
- generated-minus-dropped reward: -0.5858.

The raw rows are retained so every aggregate can be independently recomputed.

`base/validation/` is the first-pass SFT-split baseline. It predates the switch
to Prime-RL's exact Qwen3 renderer and must be regenerated before final reporting
or checkpoint comparison.

## Overfit gate

`overfit_gate/step_96_adapter_renderer/` scores the learned LoRA adapter—not the
unchanged base-weight copy in the Prime-RL checkpoint—and uses the same Qwen3
renderer as training. On all 256 fixed examples it reached:

- schema validity: 1.0000;
- supported/legal output: 0.9961;
- action exactness: 1.0000 (102/102);
- broadcast exactness: 0.9740 (150/154);
- phase-balanced selection score: 0.9870.

This passed the warm-start promotion gate and authorized the full stage-1 SFT
run. Held-out test data remains untouched until a checkpoint is selected using
validation data only.
